# Baile Flow V14

Actualización incremental sobre V11. Mantiene la misma clave de almacenamiento `baile-flow` para preservar los datos existentes.

Cambios de esta versión:
- La lista de Alumnas muestra solo el nivel actual por modalidad.
- Se elimina la lista de Próximas clases del inicio; permanece el calendario.
- Los ciclos permiten agregar aulas por encima de las 4 estándar mediante `+ 1 aula extra`, manteniendo el cálculo proporcional.
- Se preservan las funciones anteriores de reducción proporcional, edición manual, reprogramación y demás gestión.
